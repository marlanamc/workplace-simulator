# Teacher demo

Use the normal simulator website. Both accounts use class code **TEACHER-DEMO**.
Their PINs are in the account setup message, not in this repository.

On a new device, choose **Add user**, then enter the exact account name, class
code, and PIN. Matching details sign into the existing account.

| Account | Purpose | Starting point |
| --- | --- | --- |
| Demo Start | Show a new student's experience | Fresh welcome; no completed tasks |
| Demo Tour | Preview different parts of the course | Day One, before the first email reply |

Both have learner permissions, showing the student experience without access
to real students' work.

## A short route for the meeting

1. **Opening — Demo Start (3 minutes).** Show the welcome, the choice to start
   orientation or practice clicking and scrolling, and Card options.
   Explain: “Students can begin without dragging. Practice is optional.”
2. **Email repetition — Demo Tour (4 minutes).** Open Mail from the Job Card
   if needed. Show the first reply. Explain that the next two replies repeat
   the actions with different purposes and less guidance. Help stays available.
3. **Act II — Demo Tour (2 minutes).** Open `/studio` on the same website.
   In Time machine, choose the button ending **When Something Happens**.
   Continue through the arrival screen. Show how the student uses judgment.
4. **Later independence — Demo Tour (2 minutes).** Return to `/studio` and
   choose the button ending **Scheduling the Team**. Show how responsibility
   grows. There is no need to finish the task during the demo.

Studio also shows the wider course and which activities are playable. Use it
yourself during the presentation; students follow the Job Card.

## Reset and rehearse

- On **Demo Start**, `/studio` → **Fresh account** restores the opening.
- On **Demo Tour**, `/studio` → **Start of Day 1: Day One** restores the email
  opening. This replaces that demo account's later progress.
- Studio changes the signed-in account. Check the account name first.
- Use separate browser profiles or a normal window and a private window to keep
  both accounts ready without switching during the presentation.
- Rehearse on tomorrow's computer and internet connection. Avoid simultaneous
  use of Demo Tour by several teachers: they would share the same progress.

## Ask teachers to observe

“Where would a student need you to point, explain, or take over?”

Record the screen, what the student tried, and the help needed. Look for whether
help decreases across the three replies and transfers to the later coworker
email. Do not use speed as the success measure.
