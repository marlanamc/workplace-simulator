# Lesson 13: Tell a Credible Source From an Unreliable One

**Time:** 20 minutes total (10 + 10) · **Track:** 5 — Planning What's Next
**Task key:** `research` · **Status:** not built yet — the last lesson in
the current curriculum plan, and the one genuinely new judgment skill in
Track 5.
**Prerequisite:** Lesson 12

## We will learn...
- search for a source on a topic, and tell a credible one from an
  unreliable one — the same "spot it, don't guess" move as `handbook`,
  aimed at a new kind of judgment call.

## Before class (teacher prep) — once built
- [ ] Simulator: a library-style search tool with 3–4 planted results for a
      given topic — one obviously promotional, one clearly outdated, one a
      forum/opinion post, one a real-looking library database entry — and a
      prompt to pick which one to cite.
- [ ] Google Classroom: post the same style of search task using a real
      library database or Google Scholar, with the same kind of topic.
- [ ] Have 2–3 quick "why" talking points ready for each decoy (why the
      promotional one is weak, why outdated matters, why a forum post isn't
      a citable source) — this is a discussion lesson as much as a click
      lesson.

## Part A: Simulator (~10 min) — once built
1. Open the **Browser** → **Library Search** tab.
2. Search for the given topic.
3. Look at the 3–4 results — notice what's promotional, outdated, informal,
   or actually credible.
4. Pick the one you'd cite, and be ready to say why.

## Part B: Real Practice (~10 min)
1. Search the same style of topic in a real library database or Google
   Scholar.
2. Find one source you'd actually use.
3. Tell your teacher why you picked it — what made it feel credible?

**Optional extra challenge:** find one source you were tempted to pick at
first, and explain what made you change your mind.
