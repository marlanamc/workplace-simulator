# Lesson 1: Download It, Then Upload It to the Right Folder

**Time:** ~5 minutes · **Level:** 5 — Shared Files · **Track:** Shared Files
**Task key:** `upload-schedule` · **Status:** built (Wave 4, file confidence).
Renata's Monday email has next week's crew schedule attached. The learner
downloads it, then uploads it to the Schedules folder in Drive.
**Prerequisite:** Level 4 complete

## We will learn...
- **download** a file from an email: a copy goes to the Downloads folder.
- **upload** a file to a website: open the right folder first, then New →
  File upload, and choose the file from Downloads.
- read the page, not only the name: this week's and next week's schedules
  have almost the same name.

## Before class (teacher prep)
- [ ] Simulator: nothing to set up. Day 10 starts with Renata's email in Mail.
- [ ] Optional real practice, with permission: give learners a harmless PDF
      and ask them to find it in their own device's Downloads folder.

## Simulator practice (~5 min)
1. Open Mail. Open Renata's email, **Next week's schedule**.
2. Click **Download** on the attachment. It says *Saved to Downloads*. The file
   also appears in the PDF app's Downloads list.
3. Click **Open Drive**. Open the **Schedules** folder.
4. Click **New**, then **File upload**. The picker opens on Downloads.
5. Click a file to see its page. Choose next week's schedule (Week of Sep 21),
   not this week's (Week of Sep 14). Click **Upload**.

## What the Job Card corrects (and nothing is reset)
- Upload outside Schedules: "You are in … Renata wants the file in Schedules."
- This week's schedule: "That page says Week of Sep 14. That is this week."
- Nothing downloaded yet: the picker has no next-week file. Choosing another
  file says to download it from Renata's email first.

## Confidence check-in

## Notes for next time
- The next job (`files`) asks for *this* week's schedule. The file the learner
  just uploaded is now one of the look-alikes, so reading the week matters again.
- The simulator does not touch files on the learner's device. Transfer to a
  real Downloads folder is a pilot observation, not something the app proves.
