# Lesson 1: The Full Weekly Report

**Time:** ~15-20 minutes · **Level:** 23 — Put It All Together ·
**Track:** 22 — Put It All Together
**Task key:** `ops-report-packet` · **Status:** not built yet. This is the
biggest single lesson in the program — every app, together, in one
deliverable.
**Prerequisite:** Level 22 complete

## We will learn...
- pull together everything practiced so far into one real deliverable: a
  number from Sheets, a schedule note from Calendar, a short write-up in
  Docs, all sent as one packet through Mail. Nothing new to learn here —
  the skill is putting pieces that are each already familiar together
  under one deadline.

## Before class (teacher prep) — once built
- [ ] Simulator: the week's numbers already sitting in Sheets (needing a
      quick check, same as always), a schedule note in Calendar worth
      mentioning (e.g. an upcoming coverage gap), and a blank one-page
      summary doc in Docs to fill in before sending everything as one
      email.
- [ ] No Google Classroom post needed yet — this is optional, supplementary
      practice bundled into the Level 23 wrap-up assignment
      (`real-practice-assignment.md`), offered once this lesson is done.
      Never a gate — a student who skips it still moves on.

## Simulator practice (~15-20 min) — once built
1. Open **Sheets**, check this week's total the way you always have.
2. Open **Calendar**, note anything coming up worth flagging (a coverage gap,
   a meeting).
3. Open **Docs**, write a short one-page summary pulling both together —
   the numbers, and what's coming up.
4. Open **Mail**, attach or link the summary, and send it as one packet
   to your manager.

## Notes for next time
- This is deliberately a synthesis lesson, not a new-skill lesson — if a
  student breezes through it, that's the whole arc of the program landing
  at once. If a student struggles, it's worth identifying which specific
  earlier skill (the sheet, the calendar, the writing, the sending) is the
  actual gap, rather than treating this level itself as the problem.
