# Level 16 Real-World Practice: Finding a Real Answer Wrap-Up

**When to offer:** after a student finishes whichever path's lesson they
chose (Path A `research` or Path B `confidentiality-call`) — this closes
out Act V. This is **optional and supplementary** — a student who skips it
still moves straight on to Level 17 (Act VI, Office Administrator). Offer
it during office hours, or post it to Google Classroom for anyone who
wants the extra practice.

## Before class (teacher prep, only if offering this)
- [ ] Google Classroom (optional), Path A: post the same style of search
      task using a real library database or Google Scholar.
- [ ] Google Classroom (optional), Path B: talk through a real (or
      realistic) example of a plausible-sounding request for information
      that should still be declined.

## Student instructions (post as-is, or adapt — optional)
You just finished Act V — nice work. If you'd like extra practice, try the
real-world version of whichever path you chose:
- **Path A:** search a real library database or Google Scholar for a topic
  and pick a source you'd actually cite — be ready to say why.
- **Path B:** talk through how you'd handle a real version of the
  phone-call scenario.

## Teacher review
Skim for completion — on Path A, look for a clear "why," not just a pick;
on Path B, look for a professional, not just a correct, response.

## Notes for the teacher
- This is a genuine milestone — Act V complete, whichever path a student
  took. See `00-scope-and-sequence.md` for what's next: Act VI (Office
  Administrator, Levels 17-20) picks up the main ladder, whether or not a
  student did Act V at all.
- A student is ready for Level 17 as soon as either path's task shows
  complete in their Objectives panel, whether or not they did this
  optional practice.
