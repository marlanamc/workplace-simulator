# Lesson 1: Write to a Coworker

**Time:** ~4 minutes · **Level:** 3a — One More Thing · **Track:** One More Thing
**Task key:** `mail-etiquette` · **Status:** built — Mail opens straight into
a compose window addressed to Darnell Washington, a coworker, with a planted
scenario: he asked about extra aprons on Day One and never got an answer.
**Prerequisite:** Level 3 complete (`timeclock`, `paystub`, `shift-review`)

> **Why this sits here.** Every email up to now — the welcome thank-you, the
> safety-report attach — already modeled a professional email's shape
> without ever naming it: subject states the ask, greeting by name, purpose
> first, clean close. This is where that shape gets named out loud, and the
> first time the student writes to a coworker instead of a manager, which
> shifts the tone slightly. It's deliberately low-stakes — get it slightly
> wrong here and nothing happens — because the payoff is having the habit
> already in place for `call-out-sick`, the very next lesson, where getting
> it right actually matters.

## We will learn...
- name the shape a short work email follows: subject states the ask, first
  line gives the purpose, body gives what the person needs to act, closing
  is short with a clear next step.

## Before class (teacher prep)
- [ ] Simulator: nothing to set up — the Job Card opens Mail directly into
      the compose window, already addressed to Darnell.
- [ ] Point out the callback if it doesn't land on its own: Darnell's
      question has been sitting in the inbox since Day One. This is where
      it finally gets answered.

## Simulator practice (~4 min)
1. Open the **Browser** → **Mail**. The compose window is already open,
   addressed to Darnell.
2. Read the scenario: Maria wants you to let Darnell know about the extra
   aprons before you leave for the day.
3. Write a short reply — sentence starters are there if you want them.
4. Click **Send**.
5. In the Help drawer or class discussion, name the shape explicitly:
   subject → purpose first → the detail they need → short close.
