# Lesson 3: Send the Reply With the File

**Time:** ~4 minutes · **Level:** 1 — Day One · **Track:** 1 — Getting Started
**Task key:** `mail-attach` · **Status:** built and playable today
**Prerequisite:** Lesson 2 (`mail-reply`)

## We will learn...
*(read aloud / post on board — plain language, one idea)*
- put a file in an email before sending it, and check it's the right one
  before you attach it.

## Before class (teacher prep)
- [ ] Simulator: nothing to set up — same Mail inbox as Lessons 1 and 2.
- [ ] This is the moment to hand out the Level 1 wrap-up (see
      `real-practice-assignment.md`) — it's the smallest wrap-up in the
      whole curriculum, since Level 1 is only these 3 short lessons.

## Simulator practice (~4 min)
1. Open **Mail**, reply to Maria again the same way as Lesson 2.
2. This time, click **Attach file** before you send, and choose the safety
   report — not one of the similar-looking decoys (a photo, an old report,
   a different form).
3. Click **Send**.
4. Watch the points total in the tray go up, and the certificate pop-up —
   that's Day One done, and your first skill badge earned.

*Nothing here is real. Every wrong file pick just gets a friendly reminder.*

## Confidence check-in
- "I could reply to an email with the right file attached, at a real job." 🙂 😐 🙁
- "The part that felt hardest was: ___________"
- "If this happened at work and I wasn't sure what to do, I would: ___________"

## Notes for next time
- If a student attaches the wrong file more than once, that's worth a
  quick 1:1 check on Wednesday — it usually means they're not reading file
  names carefully, not that they don't understand attaching.
- Offer the real-world "bridge out" moment on the done screen (send a real
  short email, with a real file, to you) — it's optional, but it's the
  single highest-value five minutes in this whole level.
