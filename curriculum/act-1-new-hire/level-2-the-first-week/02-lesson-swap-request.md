# Lesson 2: Ask for a Shift Swap Through a Form

**Time:** ~5 minutes · **Level:** 2 — The First Week · **Track:** 2 — The First Week
**Task key:** `swap-request` · **Status:** built — the Portal's Shift Swap
tab has its own request form: a dropdown for which shift, a date picker for
when you can work instead, and an optional reason field.
**Prerequisite:** Lesson 1 (`schedule`)

## We will learn...
- do the same thing as Lesson 1 (ask for a swap because of a conflict), but
  through a real web form instead of an email. Many workplaces use one or
  the other — both are worth knowing.

## Before class (teacher prep)
- [ ] Simulator: nothing to set up — the Portal's Shift Swap tab shows the
      same kind of schedule conflict, with a dropdown, date picker, and
      optional reason field instead of a compose box.

## Simulator practice (~5 min)
1. Open the **Browser** → **Employee Portal** → **Shift Swap**.
2. Look at the schedule shown above the form.
3. Choose the shift that overlaps with something else in the dropdown.
4. Pick a date you could work instead.
5. Optionally, write a short reason.
6. Click **Submit request**.
