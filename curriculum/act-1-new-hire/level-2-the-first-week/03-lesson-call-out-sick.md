# Lesson 3: Tell Maria You Can't Come In

**Time:** ~4 minutes · **Level:** 2 — The First Week · **Track:** 2 — The First Week
**Task key:** `call-out-sick` · **Status:** built — the Portal's Message
Manager tab opens a short compose box addressed to Maria with a planted
"you're sick tomorrow" scenario.
**Prerequisite:** Lesson 2 (`swap-request`)

## We will learn...
- write a short message calling out sick, before a shift starts, in a way
  that gives your manager time to find coverage.

## Before class (teacher prep)
- [ ] Simulator: nothing to set up — the Portal's Message Manager tab
      opens straight into the scenario.
- [ ] This is the highest-value real-world message an hourly worker sends —
      worth calling out explicitly in class discussion, not just clicking
      through.

## Simulator practice (~4 min)
1. Open the **Browser** → **Employee Portal** → **Message Manager**.
2. Read the scenario: you woke up sick, and you're on the schedule
   tomorrow morning.
3. Write a short message to Maria saying you're sick and can't come in.
   Sentence starters are there if you want them.
4. Click **Send**.

## Confidence check-in
- "I could tell my manager I'm sick, in writing, before my shift starts." 🙂 😐 🙁
- "The part that felt hardest was: ___________"

## Notes for next time
- If a student says something like "I'd just call them," that's a good
  discussion point — many workplaces want it in writing too, so there's a
  record.
