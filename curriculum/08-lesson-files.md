# Lesson 8: Share a File the Right Way

**Time:** 20 minutes total (10 + 10) · **Track:** 4 — Growing at Work
**Task key:** `files` · **Status:** not built yet.
**Prerequisite:** Lesson 7

## We will learn...
- find a file in a shared drive (not just one inbox), and share it with the
  right permission — view, not edit, unless someone actually needs to change
  it.

## Before class (teacher prep) — once built
- [ ] Simulator: a Shared Drive tab with a small folder structure (e.g.
      Schedules, Forms, Manager Memos) and a few similar-looking decoy files,
      plus a scenario: "Share this week's schedule with the new hire — view
      only, they don't need to edit it."
- [ ] Google Classroom: post a real shared Google Drive folder with a similar
      shape (a few folders, a few similar file names) and the same style of
      sharing prompt.

## Part A: Simulator (~10 min) — once built
1. Open the **Browser** → **Shared Drive** tab.
2. Find the right file — use the folders, or search if you're not sure which
   folder it's in.
3. Share it with the person named in the scenario.
4. Choose **view** access, not **edit** — unless the scenario actually asks
   for edit access.
5. Rename the file if the scenario asks for a specific naming convention
   (e.g. `schedule-week-of-[date]`).

## Part B: Real Practice (~10 min)
1. Open the real shared Google Drive folder from Google Classroom.
2. Find the matching file.
3. Share it with your teacher's email, with the access level the prompt asks
   for.
4. Take a screenshot of the share confirmation, or tell your teacher you did
   it.

**Optional extra challenge:** share the same file with two different people
at two different access levels (one view, one edit), and explain out loud
why each person got what they got.

## Confidence check-in
- "I know the difference between view and edit access, and when each one
  matters." 🙂 😐 🙁
- "If I shared something with the wrong access by mistake, I would:
  ___________"

## Notes for next time
- Getting view vs. edit right is the actual point of this lesson — the
  folder/search mechanics are the easy part for most students. Don't rush
  past the "why view and not edit" question even if a student finds the file
  quickly.
