# Lesson 4: Tell a Credible Source From an Unreliable One

**Time:** ~5 minutes · **Level:** Deferred — not currently sequenced into a
level · **Track:** Planning What's Next
**Task key:** `research` · **Status:** not built yet — the last lesson in
this deferred track, and the one genuinely new judgment skill in it.
**Prerequisite:** Lesson 3

## We will learn...
- search for a source on a topic, and tell a credible one from an
  unreliable one — the same "spot it, don't guess" move as `handbook`,
  aimed at a new kind of judgment call.

## Before class (teacher prep) — once built and sequenced
- [ ] Simulator: a library-style search tool with 3–4 planted results for a
      given topic — one obviously promotional, one clearly outdated, one a
      forum/opinion post, one a real-looking library database entry — and a
      prompt to pick which one to cite.
- [ ] Google Classroom: post the same style of search task using a real
      library database or Google Scholar, with the same kind of topic. Have
      2–3 quick "why" talking points ready for this skill's decoys (why the
      promotional one is weak, why outdated matters, why a forum post isn't
      a citable source) — this is a discussion skill as much as a click
      skill. Whichever level this track eventually lands in should get its
      own combined real-practice wrap-up, same pattern as Level 1 and
      Level 2 — not written yet since this track isn't sequenced.

## Simulator practice (~5 min) — once built
1. Open the **Browser** → **Library Search** tab.
2. Search for the given topic.
3. Look at the 3–4 results — notice what's promotional, outdated, informal,
   or actually credible.
4. Pick the one you'd cite, and be ready to say why.
