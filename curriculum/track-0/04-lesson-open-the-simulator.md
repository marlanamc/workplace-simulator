# Lesson 0.4: Open the Simulator and Sign In

**Time:** ~10 minutes · **Track 0** (before Level 1) · **Not a simulator level**
**Task key:** none — this is the bridge INTO the simulator
**Status:** ready to teach (no app build needed)
**Prerequisite:** 0.1–0.3 (power, click, type)

## We will learn...
- open the class's practice site from a bookmark
- sign in with name + PIN + class code, and sign back in alone next time

This is the hand-off: after this lesson a student can sit down anywhere,
open the simulator, and continue without a teacher — which is the whole
asynchronous promise.

## Before class (teacher prep)
- [ ] Bookmark the simulator on every class Chromebook, named simply
      ("Práctica" / "Practice").
- [ ] Have the class code written large where everyone can see it.
- [ ] Decide the PIN rule (e.g. birth month + day) so "make up 4 numbers"
      never becomes a memory test. Students write name + PIN on a card
      they keep.
- [ ] Show the Español button on the sign-in page — students choose their
      language themselves, first thing.

## Practice (~10 min) — real Chromebook
1. Open Chrome. Click the "Practice" bookmark.
2. If you want Spanish, click **Español** at the top of the card.
3. Type your first name. Type your 4-number PIN. Type the class code from
   the board.
4. Click Continue. The practice desktop opens and the walkthrough starts —
   that walkthrough is Level 0, and it takes over from here.
5. Sign out (bottom-right corner → Sign out), then sign back in with the
   card. Doing it twice is what makes it stick.

## Confidence check-in
- "I can get back into the practice site by myself." 🙂 😐 🙁

## Notes for the teacher
If a student loses their card, their progress is under name + PIN + class
code — recreate the card, not the account. The card is scaffolding, not a
security risk: nothing in the simulator is real.
