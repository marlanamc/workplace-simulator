# Lesson 0.3: Type Your Name

**Time:** ~10–15 minutes · **Track 0** (before Level 1) · **Not a simulator level**
**Task key:** none — real Chromebook only
**Status:** ready to teach (no app build needed)
**Prerequisite:** 0.2 (can click what they aim at)

## We will learn...
- type letters, numbers, a space, and a capital letter
- fix a mistake with Backspace instead of starting over

The course's first real job (Level 1) asks for one typed sentence. This
lesson makes sure the keyboard is not the thing standing in the way.

## Before class (teacher prep)
- [ ] A place to type with zero stakes: a blank Google Doc, or the Chrome
      address bar with the page never opened.
- [ ] Know your students' first languages — accents and ñ exist on the
      keyboard, and finding them is a genuine win, not an extra.

## Practice (~10–15 min) — real Chromebook
1. Type your first name, lowercase. Look at the screen, not the keys —
   the letters appear where the blinking line is.
2. Backspace until it is gone. Mistakes cost one key, not a restart.
3. Type it again with a capital: hold Shift, press the letter, let go.
4. Type the numbers 1 2 3 4 — the same keys a PIN will use on day one.
5. Type one true sentence: "My name is ____." Space bar between words,
   period at the end.

## Confidence check-in
- "I can type a short sentence and fix my mistakes." 🙂 😐 🙁

## Notes for the teacher
Speed does not matter anywhere in this program. Hunting for letters with
one finger is a fine way to pass this lesson.
