# Level 13 Real-World Practice: Getting Ready Wrap-Up

**When to offer:** after a student finishes whichever path's lesson they
chose (Path A `enrollment` or Path B `appointment-scheduling`). This is
**optional and supplementary** — a student who skips it still moves
straight on to Level 14. Offer it during office hours, or post it to
Google Classroom for anyone who wants the extra practice.

## Before class (teacher prep, only if offering this)
- [ ] Google Classroom (optional), Path A: post a real (or realistic mock)
      college application checklist and deadline.
- [ ] Google Classroom (optional), Path B: post a mock day's appointment
      grid with one scheduling conflict to resolve.

## Student instructions (post as-is, or adapt — optional)
You just finished Level 13 in the simulator — nice work. If you'd like
extra practice, try the real-world version of whichever path you chose:
- **Path A:** look at a real college application checklist and deadline —
  what's still missing, and by when does it need to be done?
- **Path B:** resolve a real (mock) scheduling conflict the way you
  practiced, and write the confirmation message you'd send.

## Teacher review
Skim for completion, not perfection — this is about confirming the skill
holds up outside the guided environment.

## Notes for the teacher
- Both paths are equally valid choices — there's no "better" path here,
  just a better fit for where a given student is headed.
- A student is ready for Level 14 as soon as either path's task shows
  complete in their Objectives panel, whether or not they did this
  optional practice.
