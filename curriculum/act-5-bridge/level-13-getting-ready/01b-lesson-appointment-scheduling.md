# Lesson 1b: Schedule a Patient Appointment (Path B — Front Office / Healthcare Admin)

**Time:** ~15-20 minutes (whole level) · **Level:** 13 — Getting Ready ·
**Track:** 15 — Front Office / Healthcare Admin (Path B)
**Task key:** `appointment-scheduling` · **Status:** not built yet. This is
one of two optional paths through Act V — see `01a-lesson-enrollment.md`
for Path A (Prepping for BHCC). A student does one path, not both, unless
they want the extra practice.
**Prerequisite:** Level 12 complete. Choose this path if the student is
more drawn to front-office/medical-office work; choose Path A if they're
genuinely considering more schooling. Either is a fine choice, and a
student can always come back and try the other path later.

## We will learn...
- use a scheduling system to book, move, and double-check a patient
  appointment — the same "notice a conflict, fix it" judgment from
  `calendar` and `team-schedule`, in a front-office setting.

## Before class (teacher prep) — once built
- [ ] Simulator: a new Front Desk Browser tab/bookmark with a day's
      appointment grid (a few patients already booked, one open slot, one
      requested appointment that would double-book an existing slot).
- [ ] No Google Classroom post needed yet — this is optional, supplementary
      practice bundled into the Level 13 wrap-up assignment
      (`real-practice-assignment.md`), offered once this lesson is done.
      Never a gate — a student who skips it still moves on.

## Simulator practice (~15-20 min) — once built
1. Open the **Browser** → **Front Desk** tab.
2. Read the new appointment request — who, what kind of visit, when.
3. Check it against the day's grid — does it double-book an existing slot?
4. If it does, don't just force it in — offer the next open slot instead,
   the same "spot it, propose an alternative" move from `calendar`.
5. Confirm the booking and send a short confirmation message.
