# Learner sheets

One page per level, written TO the student — not teacher notes. Print one
and put it next to the computer, or post it in Classroom. English on top,
Spanish below the line; a student uses one half and ignores the other.

Rules for every sheet (keep them when adding new ones):
- One page. If it doesn't fit, the level is too big, not the font.
- Steps say what to click, in order. No explanations of why.
- Big print (14pt+). One idea per line.
- The sheet never introduces anything the app doesn't also say — it's a
  paper copy of the path, for students who trust paper more than screens.
